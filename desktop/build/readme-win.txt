AI YT Studio для Windows

Установка
1. Распакуйте архив в любую папку (правой кнопкой → «Извлечь все»).
2. Откройте папку «AI YT Studio» и запустите «Install.cmd».
   Программа скопируется в вашу папку пользователя, ярлыки появятся на рабочем столе и в меню «Пуск».
   Права администратора не нужны.

Можно и без установки: просто запустите «AI YT Studio.exe» из распакованной папки.

Первый запуск
Windows может показать окно «Система Windows защитила ваш компьютер» — так бывает с новыми программами
без цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».

Как это работает
Программа открывает ваш кабинет AI YT Studio в отдельном окне. Аккаунт, кредиты и оплата хранятся на сервере,
поэтому работают одинаково в программе, в браузере и на телефоне. Новые функции появляются сами — переустанавливать
программу не нужно.

Удаление
Запустите «Uninstall.cmd» из папки программы (%LOCALAPPDATA%\Programs\AI YT Studio).
Аккаунт и кредиты при этом не удаляются.

Требования: Windows 10 или 11, 64-бит, интернет.
