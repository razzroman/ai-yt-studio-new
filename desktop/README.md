# AI YT Studio для компьютера (Windows)

Программа открывает кабинет AI YT Studio в собственном окне со своим значком, меню и ярлыками. Аккаунт, кредиты и оплата остаются на сервере (закон о персональных данных), поэтому интерфейс обновляется вместе с сайтом и переустанавливать программу не нужно.

Сделано на Electron 33 (тот же движок, что у Chrome). Безопасность: изолированные страницы без доступа к компьютеру, внутри окна открываются только сервис, оплата ЮKassa и вход Google, остальные ссылки — в обычном браузере.

Если сервер недоступен, показывается экран «Нет связи с сервисом» с кнопкой «Попробовать снова» и переходом в демо-версию.

## Сборка

```bash
bash desktop/build/build-win.sh            # результат: desktop/dist/AI_YT_Studio_Windows_<версия>.zip
```

Скрипт скачивает Electron с GitHub, проверяет контрольную сумму, ставит значок AI YT Studio в .exe (`pe_patch.py`, без сторонних программ) и упаковывает папку с установщиком `Install.cmd` (копирует в `%LOCALAPPDATA%\Programs`, создаёт ярлыки на рабочем столе и в «Пуске», права администратора не нужны) и `Uninstall.cmd`.

Адрес сервера — поле `aiytServer` в `app/package.json` (сейчас `https://buykurs.ru`). Для проверки на своём компьютере: переменная окружения `AIYT_SERVER=http://localhost:8080`.

## Что стоит сделать перед публичной раздачей

- **Цифровая подпись** (сертификат разработчика для Windows, от ~15 тыс. ₽ в год): без неё Windows при первом запуске показывает «Система Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- Выложить архив на сайт (кнопка «Скачать для Windows» в кабинете и на лендинге) после запуска сервиса на VPS.
