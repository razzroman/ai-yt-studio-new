# AI YT Studio — интерактивный прототип

Статический сайт: прототип AI YT Studio (15 экранов, RU/EN) и демо-видео. Сборка и сервер не нужны.

- `index.html` — стартовая страница со списком экранов.
- `*.dc.html` — экраны прототипа.
- `support.js` — движок, который их отображает.
- `phone.html` — показывает экраны телефона в рамке, когда сайт открыт на компьютере.
