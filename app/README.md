# AI YT Studio — сервис, этап 1 «Основа»

Настоящие регистрация и вход, кредиты, оплата через ЮKassa и админка. Генерации (сценарий, озвучка, видео) — этап 2.

Сервис написан на Node.js 22 **без внешних библиотек**: сервер, база SQLite, шифрование и тесты — встроенные модули Node. На сервере не нужно ничего ставить через npm, а значит, нет чужого кода, который может сломаться или оказаться небезопасным.

## Что работает

| Часть | Что есть |
|---|---|
| Вход | Регистрация по email с двумя согласиями, подтверждение почты (+60 кредитов «Старта» один раз), вход, выход, восстановление пароля (ссылка на 1 час, после сброса все сеансы завершаются), вход через Google, двухфакторная защита (код из приложения), список сеансов с завершением, защита от перебора |
| Роли | Пользователь, модератор (только просмотр админки), администратор |
| Кредиты | Баланс и журнал в одной транзакции, баланс не уходит в минус, каждая операция по ссылке выполняется ровно один раз, возврат списания при сбое (для этапа 2), «История и кредиты» с фильтрами и выгрузкой CSV |
| Оплата | «Автор», «Студия», пакет кредитов; карта, СБП, SberPay, T-Pay (включаются в админке); тариф и кредиты — только после подтверждения банком: уведомлению ЮKassa сервис не верит на слово и перепроверяет платёж через API, сверяет сумму; отказ банка ничего не открывает; повторное уведомление ничего не дублирует; автопродление с сохранённой карты; без карты — возврат на «Старт» с сохранением кредитов; возврат денег из админки |
| Чеки | Магазин самозанятого в ЮKassa сам регистрирует доход в «Мой налог», отправляет чек покупателю и аннулирует его при возврате |
| Админка | Обзор (пользователи, платные, выручка, отказы, кредиты на балансах), пользователи с поиском и фильтрами, карточка пользователя (роль, тариф, начисление/списание с причиной, блокировка, платежи, возврат, история), журнал действий, настройки (способы оплаты, цены, площадки, ERID, открыта ли регистрация), выгрузка пользователей в CSV |
| Экраны | RU/EN, телефон и компьютер, клавиатура и экранный диктор; главная — лендинг прототипа, его кнопки ведут в настоящие вход и регистрацию |

Не входит в этап 1: очередь генераций, подключение AI-моделей, модули студии, публикация на площадки. На главной кабинета модули помечены «Скоро» и открываются в прототипе.

## Запуск у себя

```bash
cd app
npm start            # http://localhost:8080 — тестовый банк и письма в консоли
npm test             # 20 автотестов: вход, оплата, кредиты, права доступа
```

Письма в режиме разработки печатаются в консоль — ссылку подтверждения можно открыть оттуда.

## Размещение на VPS Beget

1. **Создайте VPS** в панели Beget: Ubuntu 24.04, 1 ядро, 1–2 ГБ памяти — хватит на этап 1. Запишите IP-адрес сервера и пароль root.
2. **Переключите домен на сервер.** В DNS Beget у `buykurs.ru` и `www` замените A-записи (сейчас они указывают на GitHub Pages) на IP сервера. В GitHub → Settings → Pages удалите свой домен — прототип останется на `razzroman.github.io/ai-yt-studio-new` и на `buykurs.ru/prototype/`.
3. **Подключитесь к серверу** (в панели Beget есть консоль) и выполните:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/razzroman/ai-yt-studio-new/main/app/deploy/setup.sh -o setup.sh
   bash setup.sh buykurs.ru ваш@email.ru
   ```
   Скрипт ставит Node.js 22, nginx и HTTPS-сертификат, запускает сервис, включает ночные резервные копии базы и файрвол.
4. **Заполните настройки** в `/etc/aiyt/app.env` (команда `nano /etc/aiyt/app.env`), затем `systemctl restart aiyt`:
   - `BOOTSTRAP_ADMIN_EMAIL` — ваша почта: после регистрации и подтверждения вы станете администратором;
   - ЮKassa, почта и Google — см. ниже. Без них сервис работает в демо-режиме: тестовый банк и письма в журнале (`journalctl -u aiyt -f`).
5. **Проверьте:** `https://buykurs.ru/api/health` отвечает `{"ok":true}`, регистрация проходит, письмо приходит.

Обновление до новой версии из GitHub: `bash /opt/aiyt/site/app/deploy/update.sh` — делает копию базы, прогоняет тесты и перезапускает сервис.

Выдать роль администратора вручную:
```bash
cd /opt/aiyt/site/app && sudo -u aiyt bash -c 'set -a; . /etc/aiyt/app.env; node --disable-warning=ExperimentalWarning src/cli.js make-admin почта@пример.ру'
```

## Подключение ЮKassa

1. Зарегистрируйте магазин как самозанятый в ЮKassa и создайте **тестовый магазин** (в личном кабинете ЮKassa есть переключатель).
2. «Интеграция» → «Ключи API» → выпустите секретный ключ. В `app.env`: `YOOKASSA_MODE=live`, `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`.
3. «Интеграция» → «HTTP-уведомления»: адрес `https://buykurs.ru/api/payments/webhook`, события `payment.succeeded` и `payment.canceled`.
4. Проверьте оплату тестовой картой из документации ЮKassa. После приёмки замените ключи тестового магазина на боевые.
5. Для автопродления ЮKassa должна включить магазину сохранение способа оплаты (запрос через менеджера).

## Почта

Unisender Go: подтвердите домен `buykurs.ru` (записи SPF и DKIM добавляются в DNS Beget), получите API-ключ. В `app.env`: `MAIL_PROVIDER=unisender`, `UNISENDER_API_KEY`, `MAIL_FROM`. Неотправленные письма видны в админке на «Обзоре».

## Вход через Google

Google Cloud Console → «APIs & Services» → «Credentials» → «OAuth client ID» (Web). Redirect URI: `https://buykurs.ru/api/auth/google/callback`. В `app.env`: `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`. Пока они пусты, кнопки Google не показываются.

## Устройство

```
app/
  src/server.js        запуск, продление тарифов раз в час
  src/app.js           маршруты API и раздача страниц
  src/db.js            схема SQLite и миграции
  src/services/        auth, credits, payments, yookassa, admin, settings, mail, audit
  public/              экраны: auth.html (вход), index.html + views.js (кабинет и админка), mock-pay.html (тестовый банк)
  test/                автотесты (node --test)
  deploy/              setup.sh, update.sh, backup.sh, nginx.conf, aiyt.service, app.env.example
```

Данные пользователей хранятся на сервере в России (VPS Beget), пароли — в виде хэша scrypt, сеансы — в виде хэша токена. Все действия администраторов и важные события пользователей пишутся в журнал.
